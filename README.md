# بوتی گاردنیا (Gardnya Telegram Security & AI Bot)

بوتی فەرمیی گاردنیا بۆ بەڕێوەبردن، پاراستنی ئاسایشی گروپ و وەڵامدانەوەی زیرەکانە بە زمانی کوردیی سۆرانی بە ژیریی دەستکردی Groq.

---

## 🌟 تایبەتمەندییەکان

1. **پاراستنی ئاسایشی گروپ (بۆ نائەدمینەکان):**
   - سڕینەوەی خۆکاری وێنە (Photos)
   - سڕینەوەی خۆکاری ڤیدیۆ (Videos & Video Notes)
   - سڕینەوەی خۆکاری GIF و فایلەکان (Documents & Animations)
   - سڕینەوەی خۆکاری ستیکەر (Stickers)
   - سڕینەوەی خۆکاری فایلی دەنگ (Voice & Audio)
   - سڕینەوەی خۆکاری لینک، پۆستی فۆڕوەردکراو و دوگمەدار (Anti-Spam & Links)
   - فیلتەری زیرەکی جنێو و وشەی ناشرین (Bad Words Filter)

2. **سیستەمی ئاگاداری و بێدەنگکردن (Warnings & Auto-Mute):**
   - تۆمارکردنی ژمارەی سەرپێچییەکان (1/3, 2/3, 3/3)
   - بێدەنگکردنی خۆکاری سەرپێچیکار لە چات دوای ٣ سەرپێچی بۆ ماوەی دیاریکراو (بۆ نموونە ٦٠ خولەک)

3. **ژیریی دەستکردی کوردی (Groq AI Sorani):**
   - وەڵامدانەوەی پرسیار و چاتی ئەندامان بە کوردییەکی زۆر سروشتی و شیرین
   - پەیامی ئامادەکراو (Smart Replies) بۆ سڵاو، چۆنیت، سوپاس، و چاتی ڕۆژانە
   - بێدەنگبوون لە کاتێکدا ئەندامێک وەڵامی ئەندامێکی تر دەداتەوە

4. **بەخێرهاتنی ئەندامانی نوێ:**
   - ناردنی پەیامی بەخێرهاتنی ڕازاوە و گەرم بۆ هەموو ئەندامێکی نوێ

---

## ⚙️ شێوازی کارپێکردن

### ١. دانانی Token لە `config.json`
فایلی `config.json` بکەرەوە و زانیارییەکان دابنێ:
```json
{
  "token": "YOUR_TELEGRAM_BOT_TOKEN",
  "botUsername": "gardny4_bot",
  "groqApiKey": "YOUR_GROQ_API_KEY",
  "groqModel": "llama-3.3-70b-versatile",
  "maxWarnings": 3,
  "autoMuteMinutes": 60
}
```

### ۲. هەڵکردنی بوت لە ڕێگەی Python:
```powershell
pip install -r requirements.txt
python main_bot.py
```
یاخود تەنها دوو کلیک لەسەر `start_python.bat` بکە.

### ۳. هەڵکردنی بوت لە ڕێگەی PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\bot.ps1
```
یاخود تەنها دوو کلیک لەسەر `start_powershell.bat` بکە.

## 👮 فرمانەکانی بەڕێوەبەر (Admin Commands)

- `/warn` - ئاگادارکردنەوەی بەکارهێنەر (بە ڕیپڵای)
- `/warnings` - پیشاندانی ژمارەی ئاگادارییەکانی بەکارهێنەر
- `/clearwarnings` - سڕینەوەی هەموو ئاگادارییەکانی بەکارهێنەر
- `/mute 30m` - بێدەنگکردنی بەکارهێنەر بۆ ماوەی دیاریکراو (30m, 2h, 1d)
- `/unmute` - لادانی بێدەنگی لەسەر بەکارهێنەر
- `/ban` - دەرکردن و باندکردنی بەکارهێنەر لە گروپ
- `/unban <user_id>` - لادانی باند لەسەر بەکارهێنەر بەپێی ئایدی
- `/setrules <دەقی یاسا>` - دانانی یاساکانی گروپ
- `/rules` - پیشاندانی یاساکان
- `/id` - پیشاندانی ئایدی چات و بەکارهێنەر
- `/help` - پیشاندانی ڕێنمایی و تەواوی فرمانەکان
